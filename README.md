# John Morales — carpintería a medida (v2)

Landing page estática con soporte PWA para GitHub Pages / Cloudflare Pages.

## Archivos principales
- `index.html`: contenido de la página y botón de instalación.
- `styles.css`: diseño responsive.
- `script.js`: menú móvil, instalación PWA y registro del service worker.
- `manifest.webmanifest`: nombre, iconos y modo de instalación.
- `sw.js`: caché de archivos principales para visitas posteriores y uso básico sin conexión.
- `assets/`: iconos y las tres fotografías proporcionadas para esta propuesta.
